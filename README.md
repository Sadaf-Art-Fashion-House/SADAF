# SADAF
SADAF | Art &amp; Fashion House - A luxury Arabic art and fashion platform with AI Studio
SADAF | Art & Fashion House

A luxury Arabic art and fashion platform that celebrates Egyptian and Arabic culture through modern fashion and AI-powered design tools.

Overview

SADAF is a platform that blends art and technology into one experience. Every piece is a fusion of handcrafted artistry and intelligent design, built to bring Arabic heritage to a global audience.

Features

- Home: Cinematic hero with luxury motion aesthetics
- Arts: Curated gallery of handmade crafts, calligraphy, and digital art
- Fashion: Luxury collections for men, women, and kids
- AI Studio: Generate custom clothing designs using AI
- Store: Shop curated art and fashion pieces
- Gallery: Museum-style virtual exhibition space

Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Node.js

Getting Started

npm install
npm run dev

Open http://localhost:3000

Vision

SADAF is built to become a globally recognized Arabic fashion and art platform, where ancient heritage meets modern silhouettes, powered by AI and crafted by hand.
